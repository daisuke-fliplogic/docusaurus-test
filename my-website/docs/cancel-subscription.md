# 有料プランの解約方法

マイページから、いつでもご自身で有料プランを解約できます。サポートへのご連絡は不要です。

## 解約手順

1. ログイン後、画面上部の **マイページ** を開きます。
2. プラン情報セクションにある **解約する** ボタンをクリックします。
3. 確認画面が表示されるので、内容を確認し **解約を確定する** ボタンをクリックします。
4. 「当月末での解約を受け付けました」というメッセージが表示されたら、手続き完了です。

:::tip[ヒント]
解約手続き後も、**当月末まで**は引き続き有料プランの全機能をご利用いただけます。翌月1日以降に無料プランへ切り替わります。
:::

:::warning[返金について]
日割り計算での返金は行われません。月途中での解約でも、当月分の料金は発生します。解約タイミングにご注意ください。
:::

## よくある質問

<details>
<summary>解約後すぐに使えなくなりますか？</summary>

いいえ。解約手続き後も**当月末まで**は有料プランの全機能をそのままご利用いただけます。翌月1日に無料プランへ自動的に切り替わります。

</details>

<details>
<summary>解約を取り消すことはできますか？</summary>

当月末までであれば、再度 **マイページ** から有料プランを契約し直すことで、引き続きご利用いただけます。

</details>

<details>
<summary>返金はされますか？</summary>

日割りでの返金には対応しておりません。月の途中で解約された場合でも、当月分の料金はご請求となります。

</details>

:::info[お困りの場合]
解約ボタンが表示されない、またはエラーが発生する場合は、お手数ですがサポート窓口までお問い合わせください。
:::
