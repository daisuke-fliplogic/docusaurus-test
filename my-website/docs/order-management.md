## 概要

お客様から注文をいただいた内容を入力し受注処理を行います。
作成した受注伝票から注文請書の印刷ができます。

---

## 受注入力

![受注入力画面](/guide-media/01GW8ERDE373XVV8GPM323XEJZ)

### メニューボタン

| ボタン名 | 説明 |
| --- | --- |
| **新規** | 新規で受注伝票を作成します。 |
| **保存** | 作成した受注伝票を保存します。 |
| **印刷** | 受注請書を印刷します。 |
| **コピー** | 作成した受注伝票をコピー（複写）します。 <br /> ※受注、発注伝票へのコピー や出荷、売上伝票への引当が可能です。 |
| **送信** | 作成した受注伝票をメール送信します。 <br /> ※メール送信方法については下記ヘルプページ参照 <br /> [メール送信機能](/hc/ja/articles/900004692046) |
| **削除** | 作成した受注伝票を削除します。 |
| **その他** | 売上商品一覧の確認や一括発注等その他の操作を行います。 |
| **戻る** | 受注一覧画面に戻ります。 |

### 入力項目

| 項目 | 説明 |
| --- | --- |
| **受注日** | 受注日を入力します。 |
| **取引区分** | 受注伝票の取引方法を選択します。 <br /> ・**現金売上**：売上と同時に入金処理する場合に選択します。 <br /> ・**通常売上**：得意先の請求条件に従って請求、入金処理を行う場合に選択します。 <br /> ・**材料売上**：通常売上同様、得意先への材料売上取引で使用します。 <br /> ・**立替運賃**：得意先に対して運賃など立替金請求を行う場合に選択します。 <br /> ※商品の在庫移動は行われません。 <br /> ・**景品出荷**：景品等の出荷取引を行う場合に選択します。請求（売掛）へは計上されません。 <br /> ・**売上返品**：得意先への売上返品を行う場合に選択します。 <br /> ・**材料売上返品**：売上返品同様、得意先への材料の売上返品を行う場合に選択します。 <br /> ・**立替運賃返品**：得意先に対して運賃など立替金の返品を行う場合に選択します。 <br /> ・**景品出荷返品**：景品等の出荷返品取引を行う場合に選択します。伝票表記のみ請求（売掛）へは計上されません。 |
| **倉庫** | 商品を出荷する倉庫を選択します。 |
| **納品日** | 商品を納品する予定日を入力します。 |
| **受注番号** | 受注伝票保存時に自動付番されます。 <br /> 受注番号として受注請書に印字されます。 |
| **得意先** | 得意先のコードを入力します。 <br /> 虫眼鏡又はスペースキーをクリックすると、得意先の検索ガイドが表示されます。 |
| **請求先** | 得意先のコードを入力します。 <br /> 虫眼鏡又はスペースキーをクリックすると、請求先の検索ガイドが表示されます。 |
| **代理店** | 代理店のコードを入力します。 <br /> 虫眼鏡又はスペースキーをクリックすると、代理店の検索ガイドが表示されます。 |
| **締切区分** | 得意先に登録した請求締切区分が表示されます。 <br /> 伝票単位で必要に応じて変更することができます。 <br /> 締めグループが未登録の締請求以外から締請求への変更はできません。 |
| **税計算** | 得意先に登録した消費税計算方法が表示されます。 <br /> 伝票単位で必要に応じて変更することができます。 <br /><br /> ・**直接入力**：商品明細の消費税額を直接修正する場合はこちらを選択します。 <br /> ※修正方法については「[複数の税率が発生する場合の入力方法](https://support.flamsv.com/hc/ja/articles/115013821408)」参照 |
| **担当** | ログイン担当者が表示されます。必要に応じて変更することができます。 |
| **件名** | 件名を入力します。 <br /> 最大255文字まで入力可能です。 |
| **物件番号** | 登録済み物件情報が表示されます。 <br /> 表示された物件情報を変更する場合は全角40文字以内で入力します。 |
| **見積番号** | 登録済み見積書からコピーした場合に該当する見積書番号が表示されます。 <br /> 登録済み見積書番号を入力すると、見積書の内容がコピーされます。 <br /> 虫眼鏡又はスペースキーをクリックすると、見積の検索ガイドが表示されます。 |
| **納入先** | 登録済み納入先情報が表示されます。 <br /> 表示された納入先情報を変更する場合は全角120文字以内で入力します。 |
| **備考** | 備考テンプレートに登録した備考が表示されます。 <br /> 備考を変更する場合は180文字以内（改行含む）で入力します。 |
| **印刷依頼** | 印刷依頼する場合、チェックします。 |
| **【明細部】** | |
| **区分** | 明細の取引区分を選択します。 <br /> ・**通常**：売上を入力する場合に選択します。 <br /> ・**摘要**：明細行へ摘要を入力する場合に選択します。 <br /> ・**値引**：値引を入力する場合に選択します。（売上日報で値引額で集計されます） <br /> ・**消費税**：明細行で消費税調整額を入力する場合に選択します。（税区分が「内税」や税計算方法が「直接入力」の場合のみ選択可能です） |
| **商品情報** | 商品コードを入力します。内訳1・2が登録されている場合は、それぞれ入力してください。 <br /> 登録済みの商品名、内訳1・2、および仕様・規格が表示されます。 <br /> 虫眼鏡又はスペースキーをクリックすると、商品の検索ガイドが表示されます。 <br /> 商品情報を変更する場合は、商品名は全角100文字、仕様・規格は全角255文字以内で入力します。 |
| **入数** | 商品情報に登録した入数が表示されます。 |
| **梱数** | 商品を梱数（ケース）単位の場合、梱数を入力します。 <br /> ［入数］×［梱数］で数量が自動計算されます。入数が入力されていない場合は自動計算されません。 |
| **残数** | 受注伝票から売上へ伝票複写されますと受注から引き当てられた残数が表示されます。 <br /> 新規入力の場合は、受注数がそのまま表示されます。 |
| **数量** | 商品の数量を半角数字で入力します。 |
| **単位** | 商品の単位を入力します。 <br /> 虫眼鏡又はスペースキーをクリックすると、単位の検索ガイドが表示されます。 |
| **原価** | 商品情報に登録されている原価が表示されます。 <br /> 見積からコピーした場合、コピー元の原価が表示されます。 |
| **単価** | 該当の得意先単価区分の商品情報に登録されている売上単価が表示されます。 <br /> 得意先別商品単価登録している場合は、優先して表示されます。 |
| **金額** | ［単価］×［数量］で計算されます。 <br /> 表示された金額を変更する場合は半角数字で入力します。 <br /> 金額計算の際に生じた1円未満の端数処理は得意先情報に登録されている金額端数処理に基づいて計算されます。 |
| **消費税** | 税区分、税計算方法に基づいて自動計算、表示されます。 <br /> 税計算方法が「伝票単位」「請求時」「得意先毎」の場合は表示されません。 <br /> ※内税商品の場合は、内消費税額が表示されます。 <br /> 税計算方法が「直接入力」の場合は、入力可能となります。 <br /> 税区分が「非課税」の場合は消費税計算されません。 |
| **税法** | 商品の税法を選択します。 <br /> 課税商品の場合選択必須となります。 |
| **税率** | 商品の税率を選択します。 <br /> 課税商品の場合選択必須となります。 |
| **引当/計上** | 受注伝票から引当した出荷・売上伝票の引当状況が表示されます。 <br /> ・**なし**：出荷または売上に引当がされていない状態です。 <br /> ・**一部**：受注数の一部が出荷または売上に引当されている状態です。 <br /> ・**完了**：受注数すべてが出荷または売上に引当されている状態です。 <br /> ・**取消**：引当残数管理を取消した状態です。 |
| **【合計部】** | |
| **社内メモ** | 社内向けのメモを入力します。 |
| **小計（税抜）**| 受注伝票の明細金額の合計額が表示されます。 |
| **消費税** | 受注伝票の消費税額が表示されます。 <br /> 税計算方法が「請求時」「得意先毎」の場合は表示されません。 |
| **総合計** | 受注伝票の総合計金額が表示されます。 <br /> ［小計］+［消費税］で計算されます。 |
| **原価計** | 受注伝票の原価合計が表示されます。 |
| **粗利益** | 受注伝票の粗利益が表示されます。 <br /> ［小計（税抜）］-［原価計］で計算されます。 |
| **粗利率** | 受注伝票の粗利益率が表示されます。 <br /> ［粗利益］÷［小計（税抜）］×100で計算されます。 |

## 売上商品一覧

![売上商品一覧画面](/guide-media/01GW8ER9RQ0S40S5T5W9KSMEHC)

商品コード、商品名をクリックすると受注伝票明細に商品がセットされます。
伝票番号をクリックするとその売上伝票へ移動します。

### 項目

| 項目 | 説明 |
| --- | --- |
| **売上日** | 売上商品一覧の確認をしたい売上日を範囲指定します。 <br /> 1ヶ月前から今現在までが初期表示されます。 <br /> ※「デフォルト表示日数」を設定している場合は指定日数前から今現在までが初期表示されます。 |
| **商品名** | 商品を指定します。 <br /> 指定がない場合はすべての商品が対象となります。 |

| **承認要否** | 承認要否を選択します。 <br /> ・**指定しない**：承認の要否に関わらず全ての伝票を検索します。 <br /> ・**承認が必要な伝票のみ**：承認が必要な伝票のみ検索します。 <br /> ・**承認不要な伝票のみ**：承認が不要な伝票のみ検索します。 <br /> ※承認機能がONの場合のみ表示されます。 |

| **その他** | 削除済み伝票も表示する。 |
| **作成日** | 受注を作成した日を期間指定します。 |

## 注文請書印刷

![注文請書印刷画面](/guide-media/01KFJ2Q755JJ25JM072AFRRZ2W)

### 項目

| 項目 | 説明 |
| --- | --- |
| **受注日** | 印刷したい注文請書の受注日を範囲指定します。 |
| **得意先** | 印刷したい得意先コードを指定します。 <br /> 虫眼鏡又はスペースキーをクリックすると、得意先の検索ガイドが表示されます。 <br /> 印刷したい見積番号を指定します。一括印刷の場合は指定しません。 |
| **受注番号** | 印刷したい受注番号を指定します。一括印刷の場合は指定しません。 |
| **担当** | 印刷したい担当者コードを指定します。 <br /> 虫眼鏡又はスペースキーをクリックすると、担当者の検索ガイドが表示されます。 |
| **倉庫** | 印刷したい倉庫（得意先）コードを指定します。 <br /> 虫眼鏡又はスペースキーをクリックすると、倉庫の検索ガイドが表示されます。 |
| **出力フォーマット**| 指定した出力フォーマットで、注文請書を出力可能です。 |
| **印刷依頼** | 印刷依頼のある伝票のみを印刷する場合、チェックします。 |
| **承認状態** | 承認済みの伝票のみを印刷する場合、チェックします。 |
| **PDFプレビュー履歴**| 未プレビューの伝票のみを出力する場合、チェックします。 |
| **カスタムフィールド**| カスタムフィールドの値で絞り込みを行う場合入力します。 <br /> ※プロフェッショナルプランのみ |

## 受注台帳印刷

作成した受注情報を台帳形式で一括印刷します。

![受注台帳印刷画面](/guide-media/01GW5BTEGTE4AQ9GSFR63RM9KT)

### 項目

| 項目 | 説明 |
| --- | --- |
| **受注日** | 印刷したい受注日を範囲指定します。 |
| **納品日** | 印刷したい納品日を範囲指定します。 |
