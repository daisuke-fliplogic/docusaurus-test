## 概要

お客様から注文をいただいた内容を入力し受注処理を行います。
作成した受注伝票から注文請書の印刷ができます。

---

## 受注入力

![受注入力画面](/guide-media/01GW8ERDE373XVV8GPM323XEJZ)

### メニューボタン

| ボタン名 | 説明 |
| --- | --- |
| **新規** | 新規で受注伝票を作成します。 |
| **保存** | 作成した受注伝票を保存します。 |
| **印刷** | 受注請書を印刷します。 |
| **コピー** | 作成した受注伝票をコピー（複写）します。<br/>※受注、発注伝票へのコピー や出荷、売上伝票への引当が可能です。 |
| **送信** | 作成した受注伝票をメール送信します。<br/>※メール送信方法については下記ヘルプページ参照<br/>[メール送信機能](/hc/ja/articles/900004692046) |
| **削除** | 作成した受注伝票を削除します。 |
| **その他** | 売上商品一覧の確認や一括発注等その他の操作を行います。 |
| **戻る** | 受注一覧画面に戻ります。 |

### 入力項目

| 項目 | 説明 |
| --- | --- |
| **受注日** | 受注日を入力します。 |
| **取引区分** | 受注伝票の取引方法を選択します。<br/>・**現金売上**：売上と同時に入金処理する場合に選択します。<br/>・**通常売上**：得意先の請求条件に従って請求、入金処理を行う場合に選択します。<br/>・**材料売上**：通常売上同様、得意先への材料売上取引で使用します。<br/>・**立替運賃**：得意先に対して運賃など立替金請求を行う場合に選択します。<br/>※商品の在庫移動は行われません。<br/>・**景品出荷**：景品等の出荷取引を行う場合に選択します。請求（売掛）へは計上されません。<br/>・**売上返品**：得意先への売上返品を行う場合に選択します。<br/>・**材料売上返品**：売上返品同様、得意先への材料の売上返品を行う場合に選択します。<br/>・**立替運賃返品**：得意先に対して運賃など立替金の返品を行う場合に選択します。<br/>・**景品出荷返品**：景品等の出荷返品取引を行う場合に選択します。伝票表記のみ請求（売掛）へは計上されません。 |
| **倉庫** | 商品を出荷する倉庫を選択します。 |
| **納品日** | 商品を納品する予定日を入力します。 |
| **受注番号** | 受注伝票保存時に自動付番されます。<br/>受注番号として受注請書に印字されます。 |
| **得意先** | 得意先のコードを入力します。<br/>虫眼鏡又はスペースキーをクリックすると、得意先の検索ガイドが表示されます。 |
| **請求先** | 得意先のコードを入力します。<br/>虫眼鏡又はスペースキーをクリックすると、請求先の検索ガイドが表示されます。 |
| **代理店** | 代理店のコードを入力します。<br/>虫眼鏡又はスペースキーをクリックすると、代理店の検索ガイドが表示されます。 |
| **締切区分** | 得意先に登録した請求締切区分が表示されます。<br/>伝票単位で必要に応じて変更することができます。<br/>締めグループが未登録の締請求以外から締請求への変更はできません。 |
| **税計算** | 得意先に登録した消費税計算方法が表示されます。<br/>伝票単位で必要に応じて変更することができます。<br/><br/>・**直接入力**：商品明細の消費税額を直接修正する場合はこちらを選択します。<br/>※修正方法については「[複数の税率が発生する場合の入力方法](https://support.flamsv.com/hc/ja/articles/115013821408)」参照 |
| **担当** | ログイン担当者が表示されます。必要に応じて変更することができます。 |
| **件名** | 件名を入力します。<br/>最大255文字まで入力可能です。 |
| **物件番号** | 登録済み物件情報が表示されます。<br/>表示された物件情報を変更する場合は全角40文字以内で入力します。 |
| **見積番号** | 登録済み見積書からコピーした場合に該当する見積書番号が表示されます。<br/>登録済み見積書番号を入力すると、見積書の内容がコピーされます。<br
